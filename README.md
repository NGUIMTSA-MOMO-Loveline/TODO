
# Todo List – Projet Python

Application de gestion de tâches développée en Python et utilisable directement depuis le terminal.

## Fonctionnalités

- Ajouter une nouvelle tâche.
- Afficher la liste des tâches.
- Consulter le statut de chaque tâche.
- Modifier le statut d'une tâche : « À faire » ou « Fait ».
- Quitter l'application.

## Technologies utilisées

- **Langage :** Python 3.
- **Environnement :** Terminal / Console.

## Notions de programmation

- Fonctions Python.
- Listes (`list`).
- Conditions (`if`, `elif`, `else`).
- Boucles (`while`).
- Gestion des entrées utilisateur (`input`).
- Manipulation des données.

## Installation et lancement

### Prérequis

- Python 3 installé sur votre ordinateur.

### Cloner le projet

```bash
git clone URL_DU_DEPOT
```

### Accéder au dossier

```bash
cd NOM_DU_PROJET
```

### Lancer l'application

```bash
python3 todo.py
```

## Utilisation

Au lancement, un menu propose plusieurs actions :

| Choix | Action |
|---|---|
| 1 | Créer un todo |
| 2 | Afficher les todos |
| 3 | Consulter les statuts |
| 4 | Modifier le statut |
| 0 | Quitter |

Les tâches sont stockées en mémoire pendant l'exécution du programme.

## Contexte du projet

Projet académique réalisé dans le cadre de l'apprentissage de Python.

Ce projet permet de mettre en pratique les bases de la programmation, la manipulation des listes, les fonctions et la gestion des interactions utilisateur.
